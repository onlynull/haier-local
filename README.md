# 海尔本地

Home Assistant 自定义集成，在局域网内控制海尔智家设备。当前固定接入两台产品：

- 卡萨帝 501升十字对开门冰箱 `BCD-501WGCTDM4SSU1`
- 云溪 16升双循环恒温燃气热水器 `JSQ31-16KN7SFRAGU1`

运行时通过 TCP `56800` 本地长连接读写状态，不走云端控制通道。登录后按上面两款型号从账号匹配模块号；局域网地址在安装时填写，均不写入仓库。

## 登录说明

安装时需要填写海尔智家手机号和密码。登录用于从海尔云端匹配这两台设备的模块号，并获取 `LocalKey`。拿到密钥后，状态推送和控制都在局域网完成。密钥轮换或缓存失效时，集成会再次使用同一组账号刷新 `LocalKey`。

## 安装

把 `custom_components/haier_local` 放到 Home Assistant 配置目录：

```text
/config/custom_components/haier_local/
```

重启 Home Assistant，在「设置 → 设备与服务 → 添加集成」中搜索 **海尔本地**，填写：

- 海尔智家手机号
- 海尔智家密码
- 冰箱局域网 IP
- 热水器局域网 IP

模块号由登录后的设备列表按型号自动匹配。账号密码保存在 Home Assistant 的 Config Entry 中。LocalKey 缓存在 `/config/.storage/haier_local/`，不含密码。

## 设备与实体

### 卡萨帝 501升十字对开门冰箱

| 类型 | 实体 |
| --- | --- |
| 气候 | 冷藏室、冷冻室、变温室 |
| 选择 | 第二变温室（0°保鲜 / 冰镇 / 珍品 / 母婴） |
| 开关 | 智能模式、假日模式、夜间模式、细胞级保鲜、分时节电、强制化霜、节电和杀菌相关 |
| 数值 | 显示亮度、夜间模式亮度 |
| 传感器 | 各舱温度、环境温湿度、杀菌进度 |
| 二进制 | 四扇门、杀菌模块、故障 |

### 云溪 16升双循环恒温燃气热水器

| 类型 | 实体 |
| --- | --- |
| 热水器 | 开关、目标温度、出水温度，常用运行状态放在属性里 |
| 开关 | 安全锁、节能、ECO、智能节能、智能感温、恒温加热、UV杀菌、内循环、零冷水单次/预约/全程循环（互锁）等 |
| 选择 | 增压模式、瀑布浴 |
| 数值 | 单次预约时长、静音预约时长、语音音量 |
| 传感器 | 进水/回水/室内温度、水流量、功率、CO、甲烷 |
| 二进制 | 火焰、风机、水流、正在用水、防冻、故障 |

未单独建实体的字段（含热水器预约时段）收进每台设备的 **详细状态** 诊断传感器属性，避免堆出上百个实体。

## 署名

- 本地控制协议：中国区海尔智家模块 TCP 56800，uSS/UWT + AES LocalKey。写指令使用 haismart CAE `0x2714` + OLD-EPP `5Dxx`。
- 安装登录：海尔智家账号，用于匹配模块号并获取 LocalKey。
- 品牌图标：海尔 Haier 标识，仅用于本集成识别。

## 注意

设备类型写死为上面两台产品，不会按账号自动发现其它电器。
